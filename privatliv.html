Privatlivspolitik for SnartDansk.dk

Sidst opdateret: 26. januar 2026

1. Dataansvarlig

Denne hjemmeside drives uafhængigt og er ikke tilknyttet offentlige myndigheder.

Kontakt: snartdansk@proton.me

2. Hvilke data indsamler vi?

Vi indsamler ingen personoplysninger fra dig som bruger.

  • Vi bruger ingen cookies.
  • Vi bruger ingen tracking (som f.eks. Google Analytics eller Facebook Pixel).
  • Alle beregninger sker 100% lokalt i din egen browser.
  • Vi gemmer ikke de data, du indtaster i vores beregnere.

3. Server-logs (Hosting)

Vores hjemmeside hostes af Cloudflare Pages. For at sikre teknisk drift og sikkerhed logges følgende data automatisk:

  • Din IP-adresse (denne anonymiseres inden for 24 timer).
  • Tidspunkt for besøg og hvilke undersider, du tilgår.

Disse logs opbevares kun i kort tid (typisk 24-72 timer) til fejlsøgning og sikkerhed.

4. Tredjeparts-tjenester

Vi benytter enkelte eksterne tjenester for at sitet kan fungere:

  • Tailwind CSS CDN: Vi henter design-filer fra cdn.tailwindcss.com. Denne tjeneste kan se din IP-adresse og browser-info, når filerne indlæses.
  • Stripe: Hvis du vælger at støtte projektet økonomisk via betalingslinket, ledes du direkte til Stripe. Stripe fungerer her som uafhængig databehandler for dine betalingsoplysninger og har sin egen privatlivspolitik.

5. Offentligt tilgængelige data (Lov om indfødsrets meddelelse)

De navnelister og oplysninger om kommuner, der vises på siden, er hentet direkte fra Lov om indfødsrets meddelelse. Disse data er allerede offentligt tilgængelige via Folketingets hjemmeside (ft.dk). Vi indsamler ikke disse data fra dig som bruger.

6. Dine rettigheder

Da vi ikke indsamler eller opbevarer personoplysninger om dig, har vi ingen data, vi kan udlevere, rette eller slette. Hvis du har spørgsmål til vores håndtering af data, er du dog altid velkommen til at kontakte os.

7. Ændringer

Denne politik kan opdateres. Ændringer træder i kraft ved offentliggørelse på denne side.
